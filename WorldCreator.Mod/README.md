# World Creator in-game prototype

Current test package: `dist\WorldCreator-0.2.144\WorldCreator`. Map Studio can create a new RGB24 geographic layer in a blank world, add named regions with editable English names, paint the mask, restore its source version with undo support, and erase to the defined base-region color. The Create world mod action checks the RegionSet, its GeographicRegionData reference, unique IDs and colors, localization records and packaged texture. Map Studio can also show a reusable PNG/JPG as an editor-only guide under existing game-defined region masks. Build 0.2.74 aligned the above/side projection labels and axes with the reference. Build 0.2.97 keeps the XYZ reference centered and places editable orbit and landing-site values beside the preview on wide displays. These previews do not change world XML; runtime orbit timing still needs an in-game check. Build 0.2.73 introduced input-readiness checks; in 0.2.77 these are no longer a separate page and run through the editor footer Create world mod action, which you have already tested. Build 0.2.72 lets Map Studio save the selected mask as a standalone PNG in Documents without overwriting existing exports. Build 0.2.71 added a Map Studio action to use a reusable library PNG as the starting mask for a selected map layer. The imported file stays unchanged; visible pixels must exactly match that layer's defined region colors, while transparent pixels are allowed. These map actions and the resulting world export still need an in-game check.

Build 0.2.111 adds a gas dropdown and an Add gas action. The choices include the nine gas types present in installed vanilla world XML plus Water found in Workshop world XML. The base-temperature curve has a clearer display card, K/°C/°F display, time-of-day labels with a Solar angle toggle, a scale-top field, and click-to-add or drag-to-edit points. Temperature values stay stored in Kelvin; the chart starts at 0 K and marks the vertical scale every 20 K. The graph is twice as tall, and its displayed time labels approximate local solar time from noon through midnight.

Built for Stationeers 0.2.6428.27798 with BepInEx 5 and StationeersLaunchPad. This prototype creates a new world mod from a built-in template. It offers curated controls for atmosphere, weather, orbit and surface/deep resource density, plus editable temperature curves and a phase-controlled, rotatable orbit preview. The Overview page groups world-list, primary-body, ambience, skybox, visual-scale and celestial-clock settings; Environment exposes maximum sun intensity alongside atmospheric controls. The Atmosphere, Weather, Orbit and Resources pages expose template-provided scalar attributes and leaf values, including strings and booleans, as well as numeric values. XML-driven page settings are grouped into rounded cards by their parent setting, keeping field labels, tooltips and values together. Starting conditions list installed profiles in a localized dropdown with IDs before copying the chosen profile into this world. An Advanced panel exposes every attribute and leaf value in the selected world's XML while preserving unchanged and unknown nodes. The Map panel overlays points of interest at the centroids of their referenced color-mask regions and lets you paint a selected region with an adjustable brush and undo the last stroke. Painted masks export as world-specific PNG assets; built-in game files remain unchanged. Gases and weather events can be added or removed, and vacuum worlds can receive a temperature curve. The Terrain panel previews selected PNG masks, validates raw heightmap size and rejects NaN/infinite float samples, and packages compiled indexed terrain files selected from Terrain Tools. It does not impose a normalized height range because the installed utility's height mapping still needs an in-game check.

## Install and try

Use the current test package: `dist\WorldCreator-0.2.144\WorldCreator`. Copy the contents of the package into `Documents\My Games\Stationeers\mods\WorldCreator`. It uses LaunchPad's standard layout: `About\About.xml` and `WorldCreator.Mod.dll` in the mod folder. Keep a single LaunchPad registration for this folder; do not register the parent `mods` folder or install an archived build alongside it. Start Stationeers and enable **StationeersWorldCreator** in your existing **WC** LaunchPad profile. Click **World Creator** to open its menu page; use **Back to Stationeers** to return to the game menu. The editor panel expands to the available screen area with a proportional margin and recalculates when the display resolution changes. Choose **Create a New World** to open a blank Overview immediately. Use the Overview **Start from an original world** card to optionally apply a vanilla preset; replacing settings asks for confirmation. A blank world starts with generic settings and no template map or terrain assets. Map Studio can create a geographic region map; add custom compiled terrain before loading the world in game. Or choose **Load a World** to select an installed mod under `Documents\My Games\Stationeers\mods`, then confirm. Workshop worlds under `steamapps\workshop\content\544550` are included. Hover setting labels or values for definitions and units. On Weather, each event is organized into identity and availability, timing, surface conditions and gameplay, separate visual-effect cards, audio, and other settings. Add or remove supported visual blocks directly on the event card, or clone an installed event; visual blocks such as Fog can be repeated and are edited or removed as individual cards. Custom weather also supports up to four independently editable and removable shell-sound cards. The installed game schema exposes one Fog field per event, so whether extra exported Fog blocks render independently still needs an in-game check. Save custom events from their cards for future projects in `Documents\My Games\Stationeers\WorldCreator\WeatherLibrary`. Add or remove keys on each recognized temperature or day/night offset curve. Curve keys use named input/output fields; interpolation controls remain under Advanced. The **Starting conditions** page copies installed profiles or creates a new condition, lets you choose the default and edit spawn references, and authors named supply crates with searchable vanilla item names, prefab IDs and quantities; custom or modded prefab IDs can still be entered directly. It exports game-shaped DynamicCrate, Item, and Quantity records to `GameData\startconditions.xml`; lander and player spawn references still point to existing game or mod definitions. The **Asset library** page copies selected files into the persistent `Documents\My Games\Stationeers\WorldCreator\AssetLibrary`, where categories and type filters organize them. Adding a library item stores a project copy and exports it under `GameData\Worlds\<world ID>\Assets`; use the displayed path in the XML field that references the asset. Edit the settings and select **Create world mod**. Restart, enable the newly created mod in LaunchPad, then start a new world using its name.

StationeersLaunchPad loads DLLs from enabled mod folders and discovers the legacy BepInEx entrypoint used by this plugin. Keep one active World Creator entry in the LaunchPad profile; do not add the whole `mods` directory as a second mod.

If the button is missing, check `BepInEx\LogOutput.log` and the game's `Player.log` for `World Creator` messages.
