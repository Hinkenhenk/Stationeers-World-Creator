# Stationeers World Creator

An in-game BepInEx mod for creating and editing custom Stationeers worlds.

The mod source, project file, and build/install notes are in [`WorldCreator.Mod`](WorldCreator.Mod/README.md). Build checks are in [`WorldCreator.Mod.Checks`](WorldCreator.Mod.Checks/Program.cs).

Current source version: **0.2.144**.
